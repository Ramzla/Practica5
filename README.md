# Mazo de Cartas

## Descripción

Programa en Java que simula el manejo de un mazo de 52 cartas. Permite crear, barajar, repartir y gestionar cartas.

## Clases

* **Carta:** representa una carta con valor y palo.
* **Palo:** enum con los cuatro palos.
* **Jugador:** administra el nombre y las cartas del jugador.
* **Mazo:** crea, baraja, reparte y gestiona las cartas.
* **Juego:** contiene el método `main()` y ejecuta el programa.

## Funcionamiento

El programa crea un mazo de 52 cartas, lo baraja, reparte 5 cartas a cada uno de 3 jugadores y muestra las cartas restantes. También permite que un jugador descarte una carta y la regrese al mazo.
